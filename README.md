    2-1、变量命名规则-变量前缀
        (0-1) 对于部分变量（如串口发送缓冲区之类的），前面不添加多余命名。
              宏定义、const变量不添加多余命名。

        (0-2)结构体的st分为大小写，
            小写的st代表辅助结构体，一般在接收、发送、辅助计算的时候使用，使用完辅助结构体后要马上将变量更新到正式结构体中
            大写的ST代表正式结构体，真正在代码中的各处调用，尽量保证一个独立变量只存在于一个正式结构体里面，不要重复定义

        命名顺序从(1)到(2)到(3)，比如底盘(CH)安全模式(SafeMode)全局(G)标志位(F)：GFCH_SafeMode
        (1) G：全局变量global       S：静态变量static
        (2) ST：结构体变量Struct    EM：枚举变量enum    F：标志位flag
        (3) GB：云台变量Gimbal      CH：底盘变量chassis


    2-2、变量命名规则-数字序号
        (0) 对于2025的并腿车，电池侧为后边，灯条侧为右边，右边为轮毂1，左边为轮毂2。

        (1) 云台云控IMU1
            底盘云控IMU2

        (2) 定义串腿腿部一侧为后方，关节电机的序号如下
            左前1  右前2  左后3  右后4

# 操作手册（结构化整理，保留原内容不改）

本节按当前代码逻辑整理“云台/摩擦轮/发射”的实际操作方式，覆盖遥控器与键鼠两套控制。

## 1. 进入可操作状态（总流程）

1. 上电后默认安全状态（ManualSafe 或 AutoSafe）。
2. 切到可控模式：
     - 遥控器流程：左拨杆置中，进入 RC 待机，再按规则起立。
     - 键鼠流程：右拨杆置中，进入 KeyMouse 待机，再按规则起立。
3. 起立后进入对应跟随/自由模式，才能进行完整云台与发射操作。

## 2. 遥控器操作（RC）

### 2.1 云台控制

- 右摇杆 Y 轴：Pitch
- 右摇杆 X 轴：Yaw

### 2.2 底盘模式与摩擦轮切换共用“拨轮上拨”

- 拨轮上拨并回正，按持续时间分流：
    - 大于 0.8s：底盘模式切换（待机->起立 / 自由->下蹲）
    - 小于等于 0.8s：切换摩擦轮安全锁（等效“开/关摩擦轮”）

### 2.3 发射（拨弹）

- 拨轮下拨并回正：单发
- 拨轮下拨持续超过 500ms：连发
- 发射间隔受 60ms 限制（软件节流）

### 2.4 摩擦轮开启判据

- 通过“拨轮短上拨并回正”触发发射安全锁翻转。
- 安全锁关闭时，摩擦轮目标转速生效；安全锁打开时，目标转速为 0。
- 仅当左右摩擦轮与目标转速误差都在 200rpm 内，判定“摩擦轮准备完毕”，允许稳定发射。

## 3. 键鼠操作（KeyMouse）

### 3.1 云台控制

- 鼠标 Y：Pitch
- 鼠标 X：Yaw
- 短按 E：云台 Yaw 旋转 180 度（同时触发底盘方向反转）

### 3.2 底盘起坐与跳跃（与云台联动常用）

- 短按 B：待机->起立
- Ctrl + B：跟随->下蹲
- Ctrl + Shift + V：跳跃触发

### 3.3 摩擦轮与发射

- 短按 F：切换发射安全锁（等效“开/关摩擦轮”）
- 鼠标左键：手动打弹
- 鼠标右键：视觉辅助打弹（需要视觉有效）
- 左/右键按下后回正：单发
- 左/右键持续超过 500ms：连发
- 发射间隔同样受 60ms 限制

## 4. 视觉辅瞄相关（云台关联）

- 在 KeyMouse 下，满足“右键按下 + 视觉已找到目标 + 小电脑帧率正常”可进入 AutoAim。
- 在 RC_Free 下，满足“视觉已找到目标 + 小电脑帧率正常”也可进入 AutoAim。
- 目标丢失或视觉帧率过低时，自动退出到基础模式。

## 5. 当前版本说明（避免误操作）

- F/G/Z/X 对应的打符模式切换函数在当前代码中保留了接口，但判定逻辑返回 false，默认未启用。
- 遥控器 Jump 触发逻辑当前注释关闭（默认不启用）。
- 若摩擦轮未达到准备条件，拨弹逻辑会退回阻尼/保持，不会持续给出有效发射步进。

## 6. 比赛前快速检查清单

1. 通信帧率正常（尤其 Hub、IMU、遥控器、视觉链路）。
2. 云台 Pitch/Yaw 方向与手感一致。
3. 摩擦轮安全锁开关动作正确（RC 短上拨 / 键鼠 F）。
4. 单发与连发判定正确（RC 拨轮下拨；键鼠左右键）。
5. 视觉链路断开时可安全回退到手动模式。
