


没问题，这部分公式推导的核心目的，就是**把左右轮受限后的总力矩，代入到底盘总功率的计算公式中，最终提取出一个关于 $U'_{yaw}$ 的一元二次方程**。

为了书写方便，我们按照图中的设定，**令 $U'_{yaw} = x$**（即我们要去求解的、降功率后的旋转力矩）。

下面我带你一步一步把这个方程展开、合并同类项，推导出 $A$、$B$、$C$。

---

### 第一步：写出受限后的左右轮总力矩

已知原公式为：
*   左轮力矩：$T_l = M_l + U_{speed} + U_{yaw}$  (公式 1.1)
*   右轮力矩：$T_r = M_r + U_{speed} - U_{yaw}$  (公式 1.2)
*   等比缩放约束：$U'_{speed} = k \cdot U'_{yaw}$  (公式 2.1)

在限制功率介入后，我们将指令替换为受限后的指令 $U'_{speed}$ 和 $U'_{yaw}$（即 $x$），可以得到受限后的实际总力矩：
1. **左轮实际力矩 $T_l$**：
   $$T_l = M_l + k \cdot x + x = \mathbf{M_l + (k+1)x}$$
2. **右轮实际力矩 $T_r$**：
   $$T_r = M_r + k \cdot x - x = \mathbf{M_r + (k-1)x}$$

---

### 第二步：代入双轮总功率模型

根据给定的电机模型（公式 3.1）：$P = \tau\Omega + k_1|\Omega| + k_2\tau^2 + k_3$
双轮底盘的总功率，等于左轮功率 + 右轮功率（注意 $k_3$ 是底盘非电机线圈常态损耗，算一次即可）。

当系统达到最大允许功率 $P_{max}$ 时，方程为：
$$P_{max} = \underbrace{(\Omega_l T_l + \Omega_r T_r)}_{\text{机械功率}} + \underbrace{k_1(|\Omega_l| + |\Omega_r|)}_{\text{摩擦等线性损耗}} + \underbrace{k_2(T_l^2 + T_r^2)}_{\text{电机铜损}} + \underbrace{k_3}_{\text{静态损耗}}$$

**把第一步得到的 $T_l$ 和 $T_r$ 强行代入进去：**
$$P_{max} = \Omega_l[M_l + (k+1)x] + \Omega_r[M_r + (k-1)x] + k_1(|\Omega_l| + |\Omega_r|) + k_2 \left[ (M_l + (k+1)x)^2 + (M_r + (k-1)x)^2 \right] + k_3$$

这就是图片中被截断的那一大串长公式的由来。

---

### 第三步：展开括号，消灭平方项

为了把上面的长公式变成 $Ax^2 + Bx + C = 0$ 的形式，我们需要把带有平方的项完全展开。

重点展开 $k_2$ 后面的那一块（完全平方公式 $(a+b)^2 = a^2 + 2ab + b^2$）：
1. 左轮力矩平方：
   $$(M_l + (k+1)x)^2 = \mathbf{M_l^2 + 2(k+1)M_l x + (k+1)^2 x^2}$$
2. 右轮力矩平方：
   $$(M_r + (k-1)x)^2 = \mathbf{M_r^2 + 2(k-1)M_r x + (k-1)^2 x^2}$$

把它们放回原方程，此时方程里到处散落着 $x^2$、$x$ 和常数。

---

### 第四步：同类项合并（提取 A, B, C）

现在我们像“捡芝麻”一样，把含有 $x^2$ 的项、含有 $x$ 的项、以及完全不含 $x$ 的项分别归类收集起来。

#### 1. 寻找 $x^2$ 的系数（即 $A$）：
只看带有 $x^2$ 的项，它们全部来自 $k_2$ 的展开式：
$$k_2 \cdot (k+1)^2 x^2 + k_2 \cdot (k-1)^2 x^2$$
把系数提出来化简：
$$A = k_2 \left[ (k+1)^2 + (k-1)^2 \right]$$
$$A = k_2 \left[ (k^2 + 2k + 1) + (k^2 - 2k + 1) \right]$$
（其中 $+2k$ 和 $-2k$ 刚好抵消）
$$A = \mathbf{k_2(2k^2 + 2)}$$
**✅ 完美印证了图中的 A。**

#### 2. 寻找 $x^1$ 的系数（即 $B$）：
含有 $x$ 一次方的项有两个来源：前面的机械功率项 $\Omega T$，以及后面平方展开的中间项 $2ab$。
*   来自前面的：$\Omega_l(k+1)x + \Omega_r(k-1)x$
*   来自后面的：$k_2 \cdot 2(k+1)M_l x + k_2 \cdot 2(k-1)M_r x$
把 $x$ 提出来，剩下的就是 B：
$$B = \mathbf{2k_2(k+1)M_l + 2k_2(k-1)M_r + \Omega_l(k+1) + \Omega_r(k-1)}$$
**✅ 完美印证了图中的 B。**

#### 3. 寻找常数项（即 $C$）：
把所有不含有 $x$ 的项（即 $x=0$ 时的项）全部抄下来，最后别忘了把左边的 $P_{max}$ 移项到右边变成 $-P_{max}$，以保证等号右侧为 0。
*   来自前面的：$\Omega_l M_l + \Omega_r M_r$
*   来自 $k_1$ 项：$k_1(|\Omega_l| + |\Omega_r|)$
*   来自后面平方项里的常数：$k_2(M_l^2 + M_r^2)$
*   末尾项和移项：$+ k_3 - P_{max}$
把它们加在一起：
$$C = \mathbf{\Omega_l M_l + \Omega_r M_r + k_1(|\Omega_l| + |\Omega_r|) + k_2(M_l^2 + M_r^2) + k_3 - P_{max}}$$
**✅ 完美印证了图中的 C。**

---

### 推导结论
经过一顿代数操作，极其复杂的非线性功率耦合问题，被死死地按在了一个初中数学级别的模型里：
**$Ax^2 + Bx + C = 0$**

此时，主控芯片只需要：
1. 把当前已知的传感器数据（转速 $\Omega$、姿态力矩 $M$、比例 $k$、限制功率 $P_{max}$ 等）代入算出 $A, B, C$ 的具体数值。
2. 算一下 $\Delta = B^2 - 4AC$。
3. 用求根公式 $x = \frac{-B \pm \sqrt{\Delta}}{2A}$，直接算出 $x$ (即受限后的 $U'_{yaw}$)。

整个过程不需要用缓慢的迭代法去逼近，**解析解一步到位**，非常适合对实时性要求极高的底层控制系统（频率高达 $f=1000Hz$）！
